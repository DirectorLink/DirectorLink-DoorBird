## DirectorLink · DoorBird 1.0.0-beta.3

**Beta.** A fix for the DoorBird tile, found on a real DoorBird.

Free, open-source Control4 driver for DoorBird video door stations. Part of [DirectorLink Drivers](https://directorlink.io/drivers). Free. No subscription, no license key, no account with us. Works on its own: DirectorLink is not required.

### File

| Driver in Composer | File |
|---|---|
| DirectorLink · DoorBird | `DirectorLink-DoorBird.c4z` |

Check the download against `SHA256SUMS.txt`. Keep the file name exactly as it is: a browser's `(1).c4z` copy installs as a separate driver.

### What changed

- **The tile shows the gate opening after a ring.** A visitor rang and the gate opened 10 seconds later: *Door Opened* fired, but the tile kept showing the ring. A ring and the gate opening now replace each other (the newer shows); motion still hides neither.

### Confirmed on a real DoorBird

DoorBird D2101KV, firmware 000152: the login, pictures, registering the events next to other apps' HTTP calls, rings, motion and the gate opening (*Door Opened*) reach Control4, and the tile shows them. A tap on the tile opens the gate; a second tap within 2 seconds sends no second pulse. Live video and a Relay Gate Controller bound to the relay are not confirmed yet (the reason for the beta).

### Updating

- **From beta.2:** **Driver → Add or Update Driver or Agent** with this file. Settings, bindings and programming stay.
- **From beta.1:** beta.2 and later add different devices, so they cannot update a beta.1 in place. Run **Remove From DoorBird** on beta.1, delete it, then add this driver (see the [beta.2 notes](v1.0.0-beta.2.md)).

Full steps: [directorlink.io/drivers/doorbird](https://directorlink.io/drivers/doorbird).
