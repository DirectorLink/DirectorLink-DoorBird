## DirectorLink · DoorBird 1.0.0

First full release. Make a DoorBird user for Control4, enter its login, and the DoorBird's rings, keypad codes, motion, RFID tags and the gate are in Control4: a **DoorBird tile** that shows what is happening at the door and opens the gate with a tap, and a **DoorBird Camera** for pictures and live video.

Free, open-source Control4 driver for DoorBird video door stations. Part of [DirectorLink Drivers](https://directorlink.io/drivers). Free. No subscription, no license key, no account with us. Works on its own: DirectorLink is not required.

### File

| Driver in Composer | File |
|---|---|
| DirectorLink · DoorBird | `DirectorLink-DoorBird.c4z` |

Check the download against `SHA256SUMS.txt`. Keep the file name exactly as it is: a browser's `(1).c4z` copy installs as a separate driver.

### Tested on

DoorBird D2101KV, firmware 000152, on Control4 OS 3: the login, pictures, registering the events next to other apps' HTTP calls, rings, motion, the gate opening (*Door Opened*), the tile, and opening the gate with a tap on the tile, confirmed in the controller's log.

### What it does

- **Two devices:** **DoorBird**, the tile in the Control4 apps (its icon shows a ring, motion, the gate opening or the DoorBird offline; a tap opens the **Gate Relay**), and **DoorBird Camera** (pictures, H.264 live video over RTSP on 554 or 8557, MJPEG fallback, a picture in notifications).
- **Eight properties:** Status (with the first thing to fix), DoorBird, Address, Username, Password, Gate Relay, Alert On Motion, Log Level. Everything else is in **Print Diagnostics**.
- **Official LAN API only**, on the home network, with a DoorBird user made for Control4 (API-Operator, Watch Always, History, Motion). A missing permission is named; without API-Operator the driver refuses events and says so.
- **Events the way Home Assistant gets them**: its own HTTP calls on the DoorBird, one per event, with a random token, in the DoorBird's schedule for each button, keypad code, motion, the RFID tags and each relay. Taken only from the DoorBird's address and with the token.
- **Leaves everything else alone**: the DoorBird app's notifications, a keypad code's own relay, other apps' HTTP calls (the official DoorBird driver's too), SIP and relays stay exactly as they were. Each entry is read just before it is written and checked right after.
- **Cleans up after itself** with Remove From DoorBird (run it before deleting the driver) and when the address changes.
- **Relays**: one Control4 relay connection per DoorBird relay for Relay Door, Gate and Garage Controllers. A pulse only, never held; no second pulse within 2 seconds.
- **Programming**: Ring (and Ring (Button n) on a DoorBird with several buttons), Keypad Code Entered, Motion Detected, Alert, RFID Read, Door Opened, DoorBird Online/Offline; Open Door, IR light, alert on motion.
- **Privacy**: the password, the event token, keypad codes and RFID tag numbers never appear in a log, Status, Print Diagnostics or the Control4 History.
- **With DirectorLink 1.10**: rings with the live picture on the phone, motion alerts, opening the gate with two taps (the DirectorLink camera agreement).

### Installing

1. Upload the file with **Driver → Add or Update Driver or Agent**.
2. In the DoorBird app, make a user for Control4 with API-Operator, Watch Always, History and Motion.
3. Search **DirectorLink**, add **DirectorLink · DoorBird**, and enter the DoorBird's IP, the user and its password.

Requirements: Control4 OS 3.3.0 or newer, Composer Pro, DoorBird firmware 000110 or newer for events. Full steps: [directorlink.io/drivers/doorbird](https://directorlink.io/drivers/doorbird).

### Updating

- **From beta.2 or beta.3:** **Driver → Add or Update Driver or Agent** with this file. Settings, bindings and programming stay.
- **From beta.1:** since beta.2 the driver adds different devices, so it cannot update a beta.1 in place. Run **Remove From DoorBird** on beta.1, delete it, then add this driver and make its bindings and programming again.

### Known issues

- **Control4 Intercom and audio/SIP are not included.** Installers who use Control4 Intercom with the DoorBird keep the official DoorBird driver for that; both can run side by side.
- **One HTTP call per event:** if a DoorBird keeps only one HTTP call per event and another app already has it, that event stays with the other app (Status says which). The D2101KV tested keeps several.
- **Relays of a paired I/O Door Controller** can be opened, but the DoorBird does not report when they open by themselves.
- **Away from home** (4Sight), pictures and live video are not expected to work: the camera page holds the home network's address.
- Live video and a Relay Gate Controller bound to the relay were not part of the field test; please report how they work for you.
