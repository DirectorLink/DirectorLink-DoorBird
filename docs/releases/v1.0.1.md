## DirectorLink · DoorBird 1.0.1

A small addition for DirectorLink: the driver now says which of its events are the DirectorLink camera events.

Free, open-source Control4 driver for DoorBird video door stations. Part of [DirectorLink Drivers](https://directorlink.io/drivers). Free. No subscription, no license key, no account with us. Works on its own: DirectorLink is not required.

### File

| Driver in Composer | File |
|---|---|
| DirectorLink · DoorBird | `DirectorLink-DoorBird.c4z` |

Check the download against `SHA256SUMS.txt`. Keep the file name exactly as it is: a browser's `(1).c4z` copy installs as a separate driver.

### What changed

- **New string variable `DIRECTORLINK_CAMERA_EVENTS` = `Alert=1,Ring=2`**: the ids of the *Alert* and *Ring* events, so DirectorLink finds them by what the driver says. It comes after the existing variables, whose order does not change, and like `DIRECTORLINK_CAMERA` it is written on every start, also after an update.
- **Print Diagnostics** shows it with the other DirectorLink variables.

### Updating

- **From 1.0.0, beta.2 or beta.3:** **Driver → Add or Update Driver or Agent** with this file. Settings, bindings and programming stay.
- **From beta.1:** since beta.2 the driver adds different devices, so it cannot update a beta.1 in place. Run **Remove From DoorBird** on beta.1, delete it, then add this driver.

Full steps: [directorlink.io/drivers/doorbird](https://directorlink.io/drivers/doorbird).
